# ARC-XR

ARC-XR to program badawczy poświęcony inteligentnej rzeczywistości rozszerzonej, adaptacyjnym interfejsom i współpracy człowieka z systemami wykorzystującymi sztuczną inteligencję.

## Główne obszary badań

Program obejmuje sześć powiązanych kierunków:

| Obszar | Pytanie badawcze |
| --- | --- |
| Adaptacja interfejsu | Kiedy system AR powinien zmieniać ilość prezentowanych informacji? |
| Stan afektywny | Jak uwzględniać indywidualne różnice i zmiany koncentracji podczas wykonywania zadań? |
| Komfort użytkownika | Jaki wpływ na doświadczenie mają opóźnienia renderowania i błędy okluzji? |
| Rozumienie sceny 3D | Czy geometria przestrzenna poprawia wskazywanie obiektów przez modele Vision–Language? |
| Weryfikacja procedur | Jak wykrywać pominięte kroki czynności manualnych przy ograniczaniu fałszywych alarmów? |
| Współdzielenie uwagi | Jak forma komunikatu agenta wpływa na wybór wspólnego obiektu i sprawność zadania? |

## Artykuły i koncepcje naukowe

[Przegląd 27 tematów publikacyjnych i ich krótkie omówienia](articles.md) obejmuje planowane manuskrypty oraz nowe kierunki badań w pięciu obszarach.

## Podejście badawcze

Planowane badania łączą kontrolowane zadania w AR, analizę modeli i eksperymenty ekranowe. Oceniane będą skuteczność interfejsów, błędy, opóźnienia, niepewność predykcji oraz obciążenie użytkownika.

Program jest na etapie opracowywania protokołów i niewielkich pilotaży. Prezentowane zagadnienia stanowią cele badawcze, a nie wyniki przeprowadzonych eksperymentów.
