# Behawioralny koszt wstrzymania adaptacji XR wobec adaptacji statycznej i reaktywnej

Ta pozycja ma identyfikator `MSC-AR-P25` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy czasowe wstrzymanie adaptacji poprawia wynik zadania względem adaptacji statycznej i reaktywnej?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
