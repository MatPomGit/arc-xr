# Wykrywanie błądzenia myślami i odzyskiwanie uwagi z EEG i okulografii

Ta pozycja ma identyfikator `MSC-AR-P09` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy połączenie EEG i okulografii pozwala wykrywać epizody błądzenia myślami w zadaniu?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
