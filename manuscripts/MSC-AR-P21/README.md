# Agent XR uczący się preferencji użytkownika w czasie

Ta pozycja ma identyfikator `MSC-AR-P21` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy uczenie się preferencji w kolejnych sesjach zwiększa trafność pomocy w XR?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
