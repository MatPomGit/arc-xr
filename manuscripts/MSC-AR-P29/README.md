# Predykcja subiektywnej niepewności decyzji z mikroruchów dłoni, spojrzenia i EEG

Ta pozycja ma identyfikator `MSC-AR-P29` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy ruch dłoni, okulografia i EEG pozwalają prognozować subiektywną pewność decyzji?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
