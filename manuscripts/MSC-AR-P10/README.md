# Adaptacyjne uczenie w VR i odroczona retencja pamięciowa

Ta pozycja ma identyfikator `MSC-AR-P10` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy adaptacja procesu nauczania w VR wiąże się z lepszą odroczoną retencją niż nauka o stałym poziomie trudności?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
