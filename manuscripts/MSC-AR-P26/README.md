# Faza ruchu dłoni a optymalny moment wyświetlania instrukcji w AR

Ta pozycja ma identyfikator `MSC-AR-P26` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy moment wyświetlenia wskazówki przed ruchem powoduje mniej błędów niż podczas ruchu?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
