# Emocjonalne lustro XR wizualizujące oszacowany stan afektywny

Ta pozycja ma identyfikator `MSC-AR-P12` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy wizualizacja oszacowanego stanu emocjonalnego zmienia samoświadomość w porównaniu z neutralną prezentacją?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
