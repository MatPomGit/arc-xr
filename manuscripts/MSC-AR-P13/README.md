# Generatywna Neuroadaptive Art Therapy w środowisku XR

Ta pozycja ma identyfikator `MSC-AR-P13` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Jak generatywne otoczenie wizualne reagujące na sygnały użytkownika wpływa na ocenę doświadczenia emocjonalnego?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
