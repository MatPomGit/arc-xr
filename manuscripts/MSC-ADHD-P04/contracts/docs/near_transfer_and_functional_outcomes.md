# ARC-ADHD independent near-transfer and functional outcome plan

Status: pre-freeze measurement specification, version 0.1.

This document defines the role and selection logic for independent cognitive near-transfer and everyday functional outcomes. It does not replace the separate audit of the future primary external emotion-regulation/dysregulation endpoint.

## 1. Measurement hierarchy

ARC-ADHD distinguishes:

1. **trained-task learning**: change inside Signal Gate or another trained task;
2. **proximal mechanism**: recovery after a controlled challenge, including (T_{rec});
3. **independent near transfer**: change on a task that was not trained and does not reuse ARC-ADHD stimuli, reward logic or regulation sequence;
4. **functional/far transfer**: change in everyday functioning reported or observed outside the game.

No lower level substitutes for a higher level.

## 2. Minimal-battery principle

The pilot should avoid a large executive-function battery.

A large set of correlated cognitive tasks would:

- increase participant fatigue;
- increase multiplicity;
- make selective reporting easier;
- blur the distinction between exploratory and confirmatory outcomes;
- create additional BYOD timing confounds.

The preferred pilot package is therefore:

- one prespecified independent inhibition task;
- at most one secondary independent flexibility/working-memory task if justified;
- one parent-rated functional measure;
- one independent informant or broad corroborating measure where feasible.

## 3. Primary candidate near-transfer task: Stop-Signal Task

Current status: preferred independent inhibition candidate, not yet frozen.

### Rationale

The Stop-Signal Task (SST) assesses response inhibition through a mechanism and trial structure distinct from the trained Signal Gate GO/NO-GO rule-switch task.

The 2019 consensus guide by Verbruggen et al. provides explicit recommendations for task design, stop-signal-delay tracking, SSRT estimation, data-quality checks and reporting.

This makes SST preferable to inventing another ad hoc inhibition task.

### Independence from Signal Gate

The independent SST must not reuse:

- Signal Gate visual assets;
- Signal Gate narrative;
- Signal Gate reward structure;
- challenge-regulation-recovery prompts;
- trained rule-switch contingencies;
- trained difficulty controller.

The task is an assessment, not a training level.

### Candidate outcomes

Primary task-level candidates:

- stop-signal reaction time (SSRT), calculated only when race-model/data-quality assumptions are satisfied;
- probability of responding on stop trials;
- go omissions;
- go-trial accuracy;
- go-trial RT distribution as a quality/process measure.

SSRT must follow a prespecified consensus-compatible estimation method.

### BYOD limitation

SSRT is timing sensitive.

When SST is administered remotely on private phones:

- use the same qualified private-phone execution profile at baseline and follow-up where possible;
- record qualification/capability profile;
- prespecify handling of material phone/profile changes;
- do not silently pool timing-sensitive results across materially different profiles;
- report accuracy/probability measures alongside SSRT;
- treat a device/profile change sensitivity analysis as mandatory when it affects the timing path.

If technical validation shows unacceptable timing heterogeneity, SST should move to a separately controlled assessment context rather than weakening the quality rules.

## 4. Secondary cognitive-flexibility outcome

Current status: construct selected, exact instrument not frozen.

The secondary task should measure set shifting/cognitive flexibility without reproducing Signal Gate rule-switch practice.

Candidate paradigms include:

- independent task-switching with different stimulus dimensions and response mapping;
- a validated card-sorting/set-shifting task.

### NIH Toolbox DCCS

The NIH Toolbox Dimensional Change Card Sort has strong developmental and psychometric support and covers the target age range.

However, the current official implementation is examiner-administered on iPad and listed in English/Spanish. It is therefore not adopted directly as the Polish Android-BYOD solution without a separate licensed/validated implementation pathway.

### Selection criteria

The eventual flexibility task should:

- have an age range including 8–12 years;
- use a stimulus/motor mapping independent of Signal Gate;
- have a documented scoring model;
- have acceptable test-retest properties;
- have a defensible Polish-language administration pathway;
- minimize reliance on raw millisecond RT if used on heterogeneous BYOD hardware;
- avoid proprietary restrictions incompatible with the study workflow.

Until these conditions are met, cognitive flexibility remains a secondary candidate rather than a frozen outcome.

## 5. Working-memory outcome

Current status: exploratory/optional.

Working memory is not required to establish the primary ARC-ADHD recovery mechanism.

A working-memory assessment should be included only if:

- the intervention explicitly trains a corresponding construct;
- the additional burden is acceptable;
- the task is independent of the game;
- its scoring and Polish administration are defensible.

Accuracy-based sequence updating/recall is preferable to a speed-dominated BYOD measure.

## 6. Functional outcome

Functional impairment is separate from ADHD symptom severity and from emotion dysregulation.

The functional outcome should capture whether everyday activities are easier, not whether the child learned the game.

### WFIRS-P

Current status: leading ADHD-specific functional candidate, Polish evidence package incomplete.

The Weiss Functional Impairment Rating Scale Parent Form has published psychometric validation in children/adolescents with ADHD and covers multiple domains of daily functioning.

A methodological review reports that WFIRS has undergone translation into Polish among multiple languages. This supports language availability, but it is not by itself evidence of a Polish child ADHD validation study.

Before freezing WFIRS-P, verify:

- exact authorized Polish version;
- current research-use/licensing terms;
- applicable age range;
- Polish psychometric evidence, if available;
- responsiveness to change;
- scoring/version;
- whether the study can administer it digitally.

### Impairment Rating Scale

Current status: strong brief alternative, Polish adaptation not verified.

The parent/teacher Impairment Rating Scale (IRS) has evidence of reliability, convergent/discriminant validity and incremental impairment information in child ADHD samples. Its brevity and parent/teacher forms make it attractive for repeated measurement.

Before use, establish:

- authorized Polish translation/adaptation;
- psychometric support for that translation;
- administration/scoring permissions;
- exact parent and teacher items used.

### SDQ impact supplement

Current status: broad corroborating candidate, not preferred as the sole functional endpoint.

The Polish SDQ has population-study evidence and includes an impact supplement concerning burden/impairment.

However, the Polish evaluation by Mazur et al. found that the original subscale structure was not fully replicated and concluded that further validation was needed. Therefore:

- the Polish SDQ can be considered for broad corroboration;
- the total/impact information may be more defensible than overinterpreting weak subscales;
- it should not automatically replace a dedicated ADHD functional impairment measure.

## 7. Independent informants

Where feasible, include a source that is not the caregiver supervising home app use.

Preferred hierarchy:

1. teacher/school informant using an authorized standardized measure;
2. blinded or allocation-unaware independent assessment;
3. caregiver outcome with explicit expectancy/credibility measurement.

Teacher data are particularly useful for testing generalization to a context in which the intervention is not delivered.

Teacher participation should remain optional when school access would make recruitment impractical, but missingness must be reported.

## 8. Functional domains relevant to ARC-ADHD

The functional package should cover, directly or through a validated instrument:

- returning to homework/school work after frustration;
- completing routines/tasks;
- conflict/interruption around everyday demands;
- classroom/learning functioning;
- peer/social functioning;
- use of regulation strategies outside the app.

ARC-ADHD-specific ad hoc questions may be collected as exploratory implementation data but must not replace the standardized functional outcome.

## 9. ADHD symptom outcome

ADHD symptom severity is an important secondary clinical outcome but is not interchangeable with function.

Before freezing the symptom measure, verify:

- parent form;
- teacher form where feasible;
- Polish validation;
- licensing;
- age coverage;
- responsiveness to treatment.

The symptom endpoint should remain secondary to the future prespecified external regulation/dysregulation primary endpoint unless the confirmatory research question is formally changed.

## 10. BYOD assessment policy

Not every external measure needs to be embedded in the ARC-ADHD application.

Three administration classes are permitted:

### Class A: questionnaire

Device timing is irrelevant beyond ordinary usability.

Suitable for parent/teacher/self-report measures.

### Class B: accuracy-dominant cognitive assessment

May be administered on BYOD if layout/input qualification passes and timing is not the main score.

### Class C: timing-sensitive cognitive assessment

Examples include SSRT.

Requires:

- qualified execution profile;
- prespecified device-change handling;
- technical timing validation;
- sensitivity analysis or controlled assessment fallback.

The outcome plan should record the administration class for each measure.

## 11. Provisional pilot measurement package

Current preferred structure:

### External primary

One emotion-regulation/dysregulation measure selected separately in `docs/outcome_measure_audit.md`.

### Mechanistic

- (T_{rec});
- unrecovered-event proportion;
- recovery data-validity/censoring summaries.

### Independent near transfer

- Stop-Signal Task, preferred inhibition candidate;
- one secondary flexibility task only after instrument/Polish-pathway audit.

### Function

- WFIRS-P as leading ADHD-specific candidate, conditional on Polish/licensing verification;
- IRS as brief alternative, conditional on Polish adaptation verification.

### Broad corroboration

- Polish SDQ total/impact information, with explicit acknowledgement of psychometric limitations.

### Optional

- teacher-rated functional/symptom source;
- exploratory working-memory outcome.

## 12. Freeze decision

Before Phase 2 pilot recruitment, freeze:

- exact measure/version;
- language/adaptation;
- licensing/permissions;
- respondent;
- assessment time points;
- primary/secondary/exploratory role;
- scoring;
- minimum valid data;
- missing-data rule;
- device administration class;
- device/profile-change rule for timing-sensitive tasks.

No measure should be promoted to primary because it produces the most favorable pilot result.

## 13. Remaining evidence gaps

Highest-priority unresolved items:

1. independent confirmation of Polish WFIRS-P child/adolescent validation and current use permissions;
2. Polish adaptation/validation status of IRS parent/teacher forms;
3. final flexibility-task choice compatible with Polish administration and Android BYOD;
4. final ADHD symptom measure and Polish teacher/parent forms;
5. responsiveness and minimally important difference for the eventual functional measure.
