# P06 — rejestr wyników

**Stan:** BRAK DANYCH EMPIRYCZNYCH. Nie przeprowadzono ani nie zweryfikowano wyników w ramach tego repozytorium.

Po uzyskaniu uprawnionych danych każdy wpis musi zawierać: identyfikator próby/eksperymentu, źródło danych i licencję, datę, numer wersji i hash kodu, liczbę niezależnych jednostek, definicję metryk, wyniki z przedziałami ufności, kryteria wykluczeń, odchylenia od protokołu oraz odnośnik do wykresów. Wyniki symulacji i pilotażu oznaczać odrębnie od badań potwierdzających.
