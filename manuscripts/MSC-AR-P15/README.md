# Adaptacyjna ekspozycja na stresory w XR

Ta pozycja ma identyfikator `MSC-AR-P15` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy ograniczona adaptacja intensywności stresora w XR zmienia tolerancję zadania względem warunku stałego?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
