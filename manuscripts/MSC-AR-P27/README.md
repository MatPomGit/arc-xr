# Odporność adaptacyjnego HUD na błędy estymacji obciążenia poznawczego

Ta pozycja ma identyfikator `MSC-AR-P27` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy adaptacyjny HUD zachowuje stabilność przy opóźnieniach i utracie sygnału obciążenia?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
