# Metapoznanie w XR: informacja zwrotna o szacowanym obciążeniu

Ta pozycja ma identyfikator `MSC-AR-P11` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy informacja o szacowanym obciążeniu poprawia metapoznawczą kalibrację użytkownika?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
