# Empatyczny awatar AI adaptujący komunikację do pobudzenia użytkownika

Ta pozycja ma identyfikator `MSC-AR-P14` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy awatar dostosowujący styl komunikacji do pobudzenia poprawia rozumienie wskazówek w XR?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
