# Wyprzedzające wykrywanie ryzyka błędu manipulacji z kinematyki dłoni i VLM

Ta pozycja ma identyfikator `MSC-AR-P28` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy połączenie kinematyki dłoni i VLM wykrywa błędny chwyt przed kontaktem skuteczniej niż same trajektorie ruchu?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
