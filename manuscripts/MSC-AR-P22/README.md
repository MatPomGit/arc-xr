# Neuroadaptive Social XR z odrębną personalizacją uczestników współpracy

Ta pozycja ma identyfikator `MSC-AR-P22` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy indywidualna adaptacja w Social XR poprawia koordynację względem wspólnej strategii dla całej grupy?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
