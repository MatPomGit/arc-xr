# Adaptacja poziomu wyzwania XR a transfer poprawnego wykonania zadań

Ta pozycja ma identyfikator `MSC-AR-P08` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy adaptacja trudności w XR poprawia transfer wykonania do nowego zadania?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
