# Kalibracja niepewności rozpoznania stanu użytkownika a selektywna abstencja adaptatora XR

Ta pozycja ma identyfikator `MSC-AR-P17` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy abstencja przy wysokiej niepewności modelu zmniejsza koszt błędnych interwencji XR?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
