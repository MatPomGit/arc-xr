# Wyjaśnialna neuroadaptacja XR a zaufanie i immersja

Ta pozycja ma identyfikator `MSC-AR-P18` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy wyjaśnienie przyczyny adaptacji wpływa na zaufanie i immersję?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
