# Adaptacja poziomu wyzwania XR a dynamika subiektywnego doświadczenia flow

Ta pozycja ma identyfikator `MSC-AR-P23` i należy do programu ARC-XR. Jest koncepcją badawczą, która wymaga oceny nowości i dopracowania protokołu przed rozpoczęciem badań.

Głównym pytaniem jest: Czy adaptacja trudności jest związana ze zmianą doświadczanego flow w trakcie zadania?

[Manuskrypt LaTeX](main.tex) jest odrębnym roboczym szkicem. Nie zawiera niepotwierdzonych wyników ani danych uczestników. Identyfikator i status pozostają zgodne z centralnym rejestrem publikacji.
