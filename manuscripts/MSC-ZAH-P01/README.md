# MSC-ZAH-P01 — Wierna rekonstrukcja naturalnych zachowań społecznych na awatarach

**Working title:** *Behavior-Preserving Retargeting of Naturalistic Social Interactions Across Human-Robot Avatar Realism*.

**Status:** `IDEA_HOLD` / koncepcja techniczna. Nie przeprowadzono walidacji, nie zebrano wyników.

**Pytanie:** czy identyczny przebieg mimiki, gestów, ruchów głowy i interakcji może być odtworzony na awatarach od robotycznych po MetaHuman bez powstania artefaktów, które zmieniają odbiór społeczny?

**Główny wynik:** błąd synchronizacji anotowanych zdarzeń społecznych oraz wierność retargetingu dla poziomów realizmu wyglądu. Nie jest to artykuł o ocenach niesamowitości.
