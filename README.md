# ARC XR: inteligentna rzeczywistość rozszerzona

ARC XR jest programem badawczym poświęconym adaptacyjnym interfejsom rzeczywistości rozszerzonej, multimodalnej analizie stanu użytkownika i współpracy człowieka z systemami sztucznej inteligencji. Aktualne materiały obejmują przede wszystkim koncepcje naukowe, protokoły i plany eksperymentów.

## Główne kierunki badawcze

| Kierunek | Problematyka |
| --- | --- |
| Adaptacja interfejsu | Prezentacja wskazówek i informacji zależnie od obciążenia użytkownika |
| Afekt i poznanie | Multimodalne pomiary koncentracji, frustracji i zmęczenia |
| Percepcja 3D | Rozumienie sceny przestrzennej i wskazywanie obiektów przez modele VLM |
| Procedury manualne | Weryfikacja kolejności czynności i wykrywanie błędów |
| Współpraca człowiek–agent | Komunikacja, współdzielenie uwagi i koordynacja działań |
| Komfort XR | Znaczenie okluzji, opóźnień i spójności obrazu dla doświadczenia użytkownika |

## Podejście metodologiczne

Badania obejmują kontrolowane zadania w AR, analizy modeli, eksperymenty ekranowe i pilotaże. Oceniane są jakość adaptacji, bezpieczeństwo procedur, skuteczność interakcji, opóźnienia, błędy oraz niepewność predykcji. Zasady odtwarzalności opisano w [REPRODUCIBILITY.md](REPRODUCIBILITY.md), a zakres odpowiedzialności w [ARCHITECTURE.md](ARCHITECTURE.md). Kwestie bezpieczeństwa i udostępniania zasobów przedstawia [SECURITY.md](SECURITY.md).
