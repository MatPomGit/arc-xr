# Rejestr decyzji architektonicznych

ADR zapisują kontekst, propozycję, alternatywy, skutki i dowody; nie zastępują kanonicznych protokołów badań.

| ADR | Dotyczy | Status |
| --- | --- | --- |
| [0001](0001-programme-boundaries.md) | Własność kodu i sześciu prac | proposed |
| [0002](0002-research-and-device-safety.md) | Dane, aparatura i bezpieczeństwo | proposed |
| [0003](0003-public-pages-boundary.md) | Izolacja publicznej strony | proposed |

Wpis ma numer, datę, status `proposed/accepted/rejected/superseded`, alternatywy, konsekwencje i wskazanie rzeczywistych testów lub decyzji. Dokument ze statusem `proposed` nie dowodzi wdrożenia ani akceptacji naukowej. Przy zmianie przyjętego ADR dodaj nowy wpis odnoszący się do poprzedniego.
