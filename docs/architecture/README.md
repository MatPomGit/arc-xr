# Architektura szczegółowa ARC-XR

Dokumentem nadrzędnym jest [ARCHITECTURE.md](../../ARCHITECTURE.md). Ten katalog wyjaśnia planowane, a nie jeszcze potwierdzone interfejsy dwóch wspólnych środowisk, pomiary i dowody.

[Komponenty](components.md) rozdzielają program badawczy od przyszłych aplikacji i bibliotek. [Przepływy danych](data-flow.md) określają granice zaufania i dokumentację sesji. [Granice pomiarów](measurement-boundaries.md) precyzują dostępność aparatury i ograniczenia walidacji.

Uzasadnienia szczególnych decyzji zapisuje [ADR](../adr/README.md). Aktualny status badań określa wyłącznie [PROJECT_STATE.yaml](../../PROJECT_STATE.yaml).
