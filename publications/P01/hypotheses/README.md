# P01 — hipotezy i operacjonalizacja

**Status:** planowana publikacja; hipotezy i procedury nie są jeszcze prerejestrowane. Nie przeprowadzono tutaj eksperymentów, nie ma wyników empirycznych ani zatwierdzenia komisji etycznej.

## H1 (robocza)

Adaptacyjny interfejs wykorzystujący multimodalną estymację obciążenia ogranicza błędy zadaniowe lub subiektywne przeciążenie względem interfejsu statycznego w porównywalnych warunkach.

## H2 (robocza)

Model multimodalny charakteryzuje się lepszą zdolnością generalizacji międzyosobniczej niż porównywalny model jednokanałowy przy z góry ustalonym budżecie obliczeniowym.

## Pytanie główne i pomiar

Czy multimodalna estymacja obciążenia poznawczego poprawia adaptację interfejsu AR względem interfejsu statycznego i adaptacji opartej na jednej modalności?

Planowany główny punkt końcowy: Odsetek błędów zadaniowych oraz/lub czas poprawnego wykonania (ostateczny jeden wynik główny do zamrożenia).

Dodatkowe punkty końcowe: NASA-TLX, dokładność estymacji obciążenia na zewnętrznych etykietach, opóźnienie adaptacji, FPS, zużycie energii, wskaźniki okoruchowe.

## Warunki zamrożenia hipotez

Przed zbieraniem danych należy wskazać jednostkę analizy (osoba, sesja, scena lub próba), kierunek kontrastu, efekt minimalnie istotny, regułę odrzucenia hipotezy zerowej i sposób kontroli wielokrotnego testowania. W protokole należy odróżnić hipotezy potwierdzające od analiz eksploracyjnych. Nie utożsamiać korelacji pomiaru fizjologicznego z przyczynowym wpływem interwencji.
