# P02 — plan ilustracji

**Status:** planowana publikacja; hipotezy i procedury nie są jeszcze prerejestrowane. Nie przeprowadzono tutaj eksperymentów, nie ma wyników empirycznych ani zatwierdzenia komisji etycznej.

1. **F1.** Architektura aktualizacji modelu afektywnego pomiędzy sesjami.
2. **F2.** Trajektoria jakości i zapominania modelu w kolejnych sesjach.
3. **F3.** Błędy i akceptowalność mikrointerwencji w warunkach kontrolnych.

Zapisuj figury wyłącznie na podstawie rzeczywistych danych lub jasno oznaczonych diagramów koncepcyjnych. Do każdej figury dołącz skrypt źródłowy, jednostki osi, opis prób i zasady przetwarzania. Nie umieszczać grafik zawierających rozpoznawalnych uczestników bez odpowiedniej zgody.
